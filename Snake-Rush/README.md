# 🐍 Snake Rush

A simple Snake game made using **HTML**, **CSS**, and **JavaScript**.  
Perfect for beginners learning web development and game logic.

---

## 🎮 Gameplay

Control the snake using arrow keys (`↑ ↓ ← →`) to collect food and grow longer.  
Don't hit the wall or yourself, or it's game over!

---


> 🎧 Background music and sound effects are included.  
> 🔊 Make sure your volume is on!
