# 🗣️ Text to Speech Generator

A simple and intuitive **Text to Speech (TTS) Generator** web application built with **HTML**, **CSS**, and **JavaScript**. This app converts typed text into spoken words using the Web Speech API.

---

## 🚀 Features

- Convert any typed text to speech instantly   
- Responsive and clean user interface  
- Works on modern browsers supporting the Web Speech API  

---

## 🛠 Technologies Used

- HTML5  
- CSS3 (Flexbox/Grid)  
- JavaScript (ES6+)  

---
