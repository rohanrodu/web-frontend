# ❌⭕ Tic-Tac-Toe Game

A classic **Tic-Tac-Toe** game built using **HTML**, **CSS**, and **JavaScript**. Play against another player with a clean, interactive, and responsive user interface.

---

## 🚀 Features

- Two-player gameplay on the same device  
- Interactive game board with clickable cells    
- Displays current player turn and game status  
- Reset button to start a new game  

---

## 🛠 Technologies Used

- HTML5  
- CSS3 (Flexbox/Grid)  
- JavaScript (ES6+)  

---
