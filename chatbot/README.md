# 🤖 Chatbot

A simple and interactive **Chatbot** web application built using **HTML**, **CSS**, and **JavaScript**. This chatbot can respond to user inputs with predefined answers, providing a conversational experience.

---

## 🚀 Features

- Real-time chat interface  
- Predefined responses to common questions  
- User-friendly and responsive design  
- Smooth message transitions    

---

## 🛠 Technologies Used

- HTML5  
- CSS3 (Flexbox/Grid, animations)  
- JavaScript (ES6+)  

---
