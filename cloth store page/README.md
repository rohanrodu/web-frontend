# 🛍️ Cloth Store Web Page

This repository contains a **static web page** for a fictional **Clothing Store**, built using **HTML**, **CSS**, and **JavaScript**. It offers an elegant layout, essential shopping features, and a smooth user experience — perfect for showcasing apparel or fashion products.

---

## ✨ Features

### 1. 🔍 Search Functionality
- A search bar is integrated into the header.  
- Users can type keywords to filter visible products in real-time.  
- Implemented with JavaScript via the `searchProducts()` function.

### 2. 🧾 Product Details Modal
- Clicking a product image opens a modal window with additional product details.
- The modal is managed using `showDetails()` and `closeModal()` functions.
- Improves interactivity without navigating away from the page.

### 3. 📱 Responsive Design

---

## 🛠 Technologies Used

- **HTML5**  
- **CSS3** (Flexbox/Grid, media queries)  
- **JavaScript (ES6)** for interactivity and DOM manipulation
