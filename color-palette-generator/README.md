# 🎨 Color Palette Generator

A simple and beginner-friendly **Color Palette Generator** web application built using **HTML**, **CSS**, and **JavaScript**. This project allows users to generate random color palettes and copy color codes with a single click.

---

## 🚀 Features

- Generate 5 random colors at once  
- Click on a color to copy its HEX code  
- Simple and easy-to-understand layout  
- Works on all modern browsers

---

## 🛠 Technologies Used

- HTML5  
- CSS3  
- JavaScript (ES5/ES6)

---

## 📁 Project Structure

color-palette-generator/  
│  
├── index.html   # Main webpage  
└── README.md    # This documentation file  

*(All HTML, CSS, and JS are in a single file for simplicity)*

---

## 🧠 How It Works

- When the page loads, it shows 5 random colors.
- Clicking the "Generate Colors" button updates the palette.
- Clicking on a color box copies its HEX code to the clipboard.
