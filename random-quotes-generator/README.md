# 💬 Random Quote Generator

A clean and modern **Random Quote Generator** web application built with **HTML**, **CSS**, and **JavaScript**. This project lets users generate inspiring quotes instantly at the click of a button.

---

## 🚀 Features

- Display random inspirational quotes with author names  
- Smooth fade-in animation when changing quotes  
- Responsive and elegant UI for all devices (mobile, tablet, desktop)  
- Simple, user-friendly interface with a modern look  

---

## 🛠 Technologies Used

- HTML5  
- CSS3 (Flexbox, transitions, gradients)  
- JavaScript (ES6+)  

---
